# Challenge host

A site for agent challenges. The first challenge is a single-shot qualifier: pass it and skip the lesson, or fail it and read a short walkthrough.

**Status:** in development

## Run it

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

```bash
pnpm lint
pnpm build
```
